# IE 工作台打点辅助（Chrome 扩展 · 内部使用）

在 IE Motion Analysis 的「分解工作台」视频上手速打点、标记循环起止，并把结果导出成工作台可直接导入的 CSV。

- **不修改系统代码、不调用私有接口、不上传任何数据。**
- 标记按工位保存在本机 `chrome.storage.local`。
- 只在 `#/workbench/:stationId` 路由显示浮层。

---

## 1. 安装（开发者模式）

1. 打开 `chrome://extensions`。
2. 右上角开启「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录：
   `extensions/ie-workbench-marker/`
4. 打开系统的分解工作台页面（`http://localhost:5173/#/workbench/<工位号>`），应看到右下角「打点辅助」浮层。

> 修改扩展代码后，在 `chrome://extensions` 点该扩展的「重新加载」，再刷新工作台页面。

---

## 2. 支持站点

| 站点 | 授权方式 |
|---|---|
| `http://localhost`、`http://127.0.0.1` | 内置，安装即生效（不区分端口） |
| 生产内网域名 | 扩展详情 →「扩展程序选项」→ 输入站点（如 `http://ie.example.local`）→「授权并启用」→ 刷新目标页面 |

说明：
- Chrome 的站点匹配模式不支持端口，因此按**主机**授权；同一主机的所有端口都覆盖。
- 授权弹窗由 Chrome 原生控制，扩展只申请该主机的访问权限，不读取其他站点。
- 生产站点建议使用固定域名；IP 直连也可以，但换 IP 后需重新添加。

---

## 3. 使用

1. 在工作台载入视频。
2. 右侧浮层实时显示主视频当前时间（秒）。
3. 在需要的时刻打点：

| 快捷键 | 动作 |
|---|---|
| `Alt+M` | 打点（普通时间点） |
| `Alt+[` | 标记循环开始 |
| `Alt+]` | 标记循环结束 |
| `Alt+Z` | 撤销最后一个标记 |
| `Alt+E` | 导出 CSV |
| `Alt+H` | 显示 / 隐藏浮层 |

4. 在浮层里选择**手别**（R/L/B）、**类型**、**描述前缀**。
5. 点「导出 CSV」。
6. 回到**产线总览 / 工位清单**，在目标工位卡片上点「导入CSV」，选择下载的文件（导入入口在工位卡片，不在工作台内部）。

> 快捷键只在焦点不在输入框时生效，避免与页面输入冲突。浮层可拖动、可收起。

### 导出规则

- 存在完整的「循环起 / 循环止」配对时：按配对导出，忽略未配对的起止点。
- 否则：按所有打点的时间顺序，导出相邻两点之间的间隔。
- 至少需要 1 段（2 个打点，或 1 对完整循环）。

### CSV 格式

```csv
序号,手别,类型,描述,时长s
1,R,其他,打点 1,1.23
2,R,其他,打点 2,0.86
```

- 与工作台导入列名一致；带 UTF-8 BOM，Excel 打开不乱码。
- **类型必须在动作词表内**（浮层下拉已列出常用合法类型，默认「其他」）。填了词表外的值，导入会被工作台校验拦截。
- 时长按 10ms 网格四舍五入，与工作台落库口径一致。
- 起始时间不导出：导入时工作台按行顺序从 0 累加时间轴。

## 4. 数据与隐私

- 标记数据只存在本机浏览器：`chrome.storage.local`，键为 `marks:<stationId>`。
- 不发起任何网络请求，不注入远程脚本，不使用 `eval`。
- 浮层使用 Shadow DOM，避免污染系统页面样式。
- 清空标记只影响当前工位；卸载扩展会一并清除本地标记。

---

## 5. 已知限制

- 只识别「分解工作台」路由；AI 自动分解页（`#/ai-segment/...`）不显示浮层。
- 视频未载入或不在可视区域时，浮层显示「—」，打点会提示先载入视频。
- 一次最多保留 500 个标记（超出按时间顺序丢弃最早的）。
- 视频源切换后会自动重新定位主视频，但极端情况下（多个大尺寸视频并存）可能选错；刷新页面即可恢复。
- 类型词表是内置常用集合；若公司动作标准新增类型，直接在浮层「类型」里输入即可，导入以工作台校验为准。

## 6. 目录结构

```
extensions/ie-workbench-marker/
├── manifest.json      MV3 清单（storage + scripting；localhost 内置注入）
├── background.js      额外站点的 content script 动态注册
├── content.js         打点浮层、快捷键、标记持久化、CSV 导出
├── popup.html/js/css  工具栏弹窗：状态、显示/隐藏、注入兜底
├── options.html/js/css 站点授权管理
└── README.md
```

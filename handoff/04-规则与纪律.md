## 1. 数据库纪律（摘要，全文以 CLAUDE.md §1 为准）

- 只连 `CN_AME@IRSCNYTFINEREPORT.ap.inalfa.local:1433`（publicUser），口令只存 `app/api/.env`。
- DDL/DML 只允许 33 张白名单表；新表三步走：实体 → migrate.ts 幂等 DDL → 更新 CLAUDE.md 白名单（用户书面同意）。
  （2026-11-20 经用户同意由 30 张扩为 33 张：`t_decomposition_task` / `t_task_station` / `t_batch_export_record`。）
- **本机（开发机）例外，已记录不豁免**：`app/api/.env` 为 `DB_HOST=localhost`、`DB_USER=sa`（开发占位配置）。
  因此 `ops:db-scope-check` 在本机**固定报 2 项 `.env` 违规**、退出码 1 —— 这是正确的信号，不是噪声：
  **本机不得用于生产部署**；部署必须在 `.env` 指向 `IRSCNYTFINEREPORT.ap.inalfa.local` / `publicUser` 的机器上执行。
  另注：`sa` 是服务器级管理员账号，切勿用于任何可达的 SQL Server。
- `CMC.dbo.*` 仅 SELECT；`CN_AME_SSO_*` 仅 OIDC 启用时只读；禁链接服务器/OPENROWSET/跨库写。
- 提交/部署前必跑 `npm run ops:db-scope-check`，失败即禁止部署。
- 生产 `synchronize=false`；表结构唯一来源 migrate.ts；手工 SQL 只放 `deploy/sql/manual/` 并登记备案。

1. **先读后动**：接手任何任务先读 `00-交接区入口.md` → `01-项目记忆.md` → `02-任务看板.md`；不重复做看板里已完成的任务。

3. **收工必留痕**：看板更新状态 + `03-开发记录.md` 追加日志；中断/被阻塞也要写（阻塞原因、需要的决策或资源）。

## 3. 工程纪律

1. **1:1 平移纪律**：换 I/O 层时计算口径零变化；`t_element` 为核心表。
2. **React 钩子全在第一个条件 return 之前**（否则登录后白屏）；受保护数据 useEffect 必须依赖 `user`。【旧平台经验】
3. **UI 改动必须真实浏览器截图验证**（puppeteer-core + 系统 Chrome；截图配 DOM 边车 JSON 机验，视觉模型会误读）。tsc+vite build 抓不住白屏和布局溢出。【旧平台经验】
4. **事务**：TypeORM 显式事务走 `BaseRepository.transaction`（内置串行锁）。【旧平台经验】
5. **测试数据收尾必须清理/复位**（冒烟工位、锁定账号、测试改密还原）。【旧平台经验】
6. **测试脚本**：UI 脚本用 `.cjs`（web 是 ESM）；改 test 的 `.ts` 后必须先 `npm run build`。【旧平台经验】
7. **规则 DB 优先于文件**；改 `app/config/rules/*.json` 后必须发布升 rv 才生效；路由顺序 `@Get('sets')` 必须在 `@Get(':code')` 之前。【旧平台经验】
8. **DTO 全字段必须 class-validator 装饰器**（whitelist 会剥未装饰字段）；错误信封 `{title,status,detail,...}` 业务字段顶层透传。【旧平台经验】
9. 每个 Agent 完成任务：更新看板 + 追加 `03-开发记录.md`。

## 4. 高频坑速查【旧平台经验，代码平移沿用】

- 本环境有 HTTP_PROXY：**curl 本地必须 `--noproxy '*'`**；探针走 127.0.0.1。
- mssql 包只在 `app/api/node_modules`；app/web 下别直连 DB。
- TypeORM `ds.query` 跨库只收**位置参数**（命名参数报错）；`desc` 是 SQL Server 保留字，裸 SQL 用 `[desc]`；tedious requestTimeout 默认 15s，大表先过滤再关联 + `requestTimeout: 60000`。
- Chrome 负 playbackRate 必抛 NotSupportedError → 倒放一律「点按后退」语义（J 键）。
- React `onClick={fn}` 会把 MouseEvent 传进可选对象参数；keydown 用无依赖数组 useEffect 保闭包新鲜，输入框聚焦必须跳过。
- CSS 恒等 transform 动画坑（fill both + to 含 translateY(0) → 弹窗错算屏幕外）：to 关键帧去 transform；fixed 浮层 createPortal 挂 body。
- 原生 select popup 在 DPI/缩放下漂移 → 一律自绘下拉（portal + getBoundingClientRect + Flip 翻转）。
- 造测试数据：V2 同手时间轴不得重叠；va_class 与类型默认不一致必须带改判标记；desc 命中例外词会被重分类。
- UI 测试遇 CMC 联动冷启动 10s+ → 先预热 API + waitForFunction，不能只 sleep。

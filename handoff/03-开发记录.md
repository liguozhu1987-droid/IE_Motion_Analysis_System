**问题（用户反馈）**
1. 分解到一半视频提示错误。

- 临时保存：工作台无本地草稿（AI 页有），未提交内容只存在内存。

**做了什么**
1. 工作台载入含 AI 要素的版本 → 顶部铜色提示条「含 N 条 AI 自动分解结果」+「复测并继续」一键按钮。

3. 复测时把本地草稿带到新版本（修复「版本号变化导致草稿不恢复」的隐患）。
4. 本地草稿：`ie-wb-draft:<stationId>`，脏则 800ms 防抖写、提交/干净即清；恢复时自动并回服务端 AI 要素（AI 成果不可丢）。
5. 视频 onError：code=2 且服务端 URL → 自动 `refreshTokens()` 一次并恢复播放（`netRetriedRef` 防循环）；文案按 code 1/2/3/4 细分。

**验证**
- `tsc --noEmit` ✅、`npm run build` ✅。
- 草稿恢复实测：服务端 3 要素 → 注入 1 条草稿 → 刷新后显示 1 条 + 提示「已恢复本地草稿（…，1 条）」+ 时间线出现该要素。

## 2026-11-21（下午，续 5）· Agent: Claude (Haiku 5.5, Claude Code 会话)

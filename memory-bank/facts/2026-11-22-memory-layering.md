# 记忆分层铁律：同一条事实只允许一个正文来源

`handoff/` 管过程与正文，`memory-bank/` 管原子结论索引；facts 卡片**只写结论 + 指针，不复制正文**。

**为什么**：本项目历史上出现过四套记忆文件各自演化、同一事实多处表述且互相矛盾（`handoff/明细/project_memory/risk_log.md` R01），导致新 Agent 读错口径后提出重复建设建议。记忆库一旦变成「第二个正文副本」，冲突必然复发。

**判定**：若一条 facts 的内容需要成段解释，说明它应该是 `handoff/明细/` 的正文，facts 里只留一行结论和路径。

**来源**：`AGENTS.md` §1 硬性约束 2、`memory-bank/README.md`「防冲突铁律」。

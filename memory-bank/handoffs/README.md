# Handoffs · 跨 Agent 交接单

状态：`pending`（待接手）/ `claimed`（已接手）/ `done`（已完成）。

**接手规则**：新会话扫描本目录，发现 `pending` 即复述摘要并把状态改为 `claimed`；
完成后改为 `done`，并在 `handoff/03-开发记录.md` 留一行结果。

> 与 `handoff/02-任务看板.md` 的分工：看板是**全局任务状态表**（待办/进行中/完成/阻塞）；
> 本目录是**单次接力的上下文包**（给下一个 Agent 的目标、已完成、卡点、下一步）。
> 两处状态须一致，看板为准。

命名：`yyyy-mm-dd-handoff-简短主题.md`。

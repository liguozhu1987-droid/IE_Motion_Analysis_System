### 4. 附带修复：后端启动崩溃（阻塞级，非前端引入）
- 现象：API 起不来 → `DataTypeNotSupportedError: Data type "boolean" in "VideoDerivative.vfr" is not supported by "mssql"`；修完又暴露 `AiLlmProfile.enabled`。
- 根因：实体写死 `type:'boolean'`，mssql 只认 `bit`；而**隔离测试走 SQLite（支持 boolean）→ 全绿漏网**。DDL 里明明是 `vfr BIT NULL` / `enabled BIT NOT NULL DEFAULT 0`，属「实体声明与迁移 DDL 必须同步」铁律的 type 版。
- 修法：去掉显式 type，交 TypeORM 按方言推断（mssql→BIT，sqlite→BOOLEAN）。已扫全部 25 个实体，其余类型无同类问题。
- 验证：重建 dist 后 API health=200。

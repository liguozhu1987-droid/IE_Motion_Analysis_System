### 拆 patch 踩坑（python 生成 git patch）
- Windows python 文本模式写 patch → \r\n，git apply 报 "unexpected line: ?"；必须 newline=''
- git apply 对**无尾 context 的 hunk** 定位失败（本 PortableGit 版本）→ 拆 hunk 必须带头尾 context
- '+' 新增行转 context 行要补 1 前缀空格；纯 '+' 空行 → 单空格 context 行
- hunk 间拼接只能单 \n（\n\n 会产生裸空行直接解析失败）
- git diff 默认不含二进制内容 → modified 二进制（截图）不能靠 patch 传递，需整体归属一个 commit

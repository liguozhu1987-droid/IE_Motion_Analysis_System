## 2. 冻结共享口径（唯一权威版）

### 2.1 数据模型（3表16字段，零新增）

- **t_station**：station_id / line_id / name / CT / TT / version(INTEGER，指向生效bol_version) / updated_by / updated_at
- **t_element**（16字段）：element_id（`{station_id}-V{bol_version}-{seq}`版本化主键）/ station_id / seq / start_ms / dur_s（有效循环观测均值）/ hand(L/R/B) / type（10类）/ desc（**TEXT(120)**：正文≤50字+改判标记≤70字）/ va_class / outlier_flag / outlier_reason / video_id / rating(0.70~1.25默认1.000) / allowance(0.05~0.30默认0.150) / std_time / bol_version
- **t_improvement**：imp_id / station_id / element_ids / waste_type / method(E/C/R/S) / measure / est_save_s / priority / status(待实施/已完成/已验证) / owner / due / before_ct / after_ct
- **std_time = dur_s × rating × (1 + allowance)**（系统计算列，禁手填；01§5.2与02§4完全一致，已冻结）
- 收益参数存 `config/benefit_params.json`（按line_id一条：rate_yuan_per_hour / daily_output / realization_rate=0.70 / configured_by / configured_at）——不新增表、不塞t_station

### 2.2 要素10类默认VA判定（裁决后终版，01§6与02§2.1已同步）

| 类型 | 默认VA | 例外（→低置信度暂定） |
|---|---|---|
| 装配 | VA | desc含返工/重装/拆 → 暂NVA |
| 使用（含加工） | VA | desc含空跑/试运行/对刀 → 暂NNVA |
| 取放 | NNVA | — |
| 预对 | **NNVA** | dur_s>2 → 暂NVA |
| 检验 | **NNVA**（规定项） | desc含返检/重复/自设/抽检复查 → 暂NVA |
| 搬运 | **NNVA** | desc含往返/再次/回取 → 暂NVA |
| 等待 | NVA | desc含节拍/同步/配合/机 → 暂NNVA |
| 寻找选择 | NVA | — |
| 持住 | NVA | — |
| 其他 | 暂NNVA（全部进待复核） | — |

判定总纲：VA=直接改变产品形态/性能（客户付费）；NNVA=不增值但**当前工艺必需**（压缩/优化）；NVA=纯浪费（目标删除）。改善优先序：删NVA→减NNVA→简VA。

### 2.3 其余冻结口径

- **6类浪费**触发器量化条件、山积图/平衡率/瓶颈榜/双手图算法：以02号文档为准（唯一来源）
- **12条ECRSA映射**、est_save_s估算式（0.3~0.8经验系数）、三因子优先级：以04号文档为准（系数W7校准）
- **收益公式**：年化收益(元/年) = 节省秒数 × 日产量 × 365 × 综合费率(元/工时) **÷ 3600** × 70%落地率（蓝图v2.1三处表述已同步补"元/工时+÷3600"单位定稿）
- **VA改判标记**（全平台统一）：desc末尾追加 `[VA改判|原:X|新:Y|理由:…(≥5字)|人:…|日期]`；确认标记 `[VA确认|类:X|规则:…|人:…|日期]`；前端解析不显示；**重算覆盖保护**=含标记要素跳过自动归类
- **封存规则**：写操作仅限 `bol_version=t_station.version` 的要素，旧版无例外拒绝写入；**version推进时机="开始复测"点击时**；提交事务=CT重算+updated_by/at；作废=删v(n+1)+version回退（同事务）；不可解封
- **浪费证据输出结构**（02→04接口）：`{waste_type, station_id, level, element_ids[], evidence, involved_dur_s}`
- **工位工时/CT口径**：Σ生效（outlier_flag=0）且非异常要素std_time；异常要素单列（数量+原因），不进山积图不进VA分母
- **2条红线**：提示+确认放行（非阻断），确认人文本标记记入measure尾部，月抽审核对
- **SOP版本**：`SOP_v{t_station.version}_{YYYYMMDD}`；方法变更现场确认记录落SOP导出页脚"现场确认：IE+班长+日期"行
